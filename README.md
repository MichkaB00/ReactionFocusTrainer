# Фокус — тренажер реакції та уваги

Лабораторна робота №1: «Створення проєкту Django та запуск сервера із Nginx».

## Що зроблено

- Реєстрація, вхід і вихід.
- Особистий кабінет із редагуванням імені та прізвища.
- Тренування швидкості реакції та концентрації уваги.
- Дані користувачів і режими тренування зберігаються в SQLite.

## Як запустити

На цьому комп’ютері відкрийте PowerShell у папці проєкту та виконайте одну команду:

```powershell
.\start.cmd
```

Команда запускає Ubuntu/WSL2, Supervisor, uWSGI та Nginx і відкриває сайт:
[http://localhost:8080/](http://localhost:8080/). Залишайте вікно PowerShell відкритим,
поки користуєтеся сайтом. Для зупинки натисніть `Ctrl+C` або закрийте вікно.
Наступного разу запустіть ту саму команду.
